# Wa-Tor Simulator 仕様書 v1.0

## 1. 概要

魚とサメが生息するトーラス状海洋世界のシミュレーター。
個体数の変動（Lotka-Volterra的挙動）を観察できる。

## 2. 動作環境

- Webブラウザ
- TypeScript / HTML / CSS
- サーバー不要・ローカル動作

## 3. 世界（海洋）

- 二次元格子（初期値 50×50）
- トーラス構造（境界なし）
  - 左端の次は右端、右端の次は左端
  - 上端の次は下端、下端の次は上端

## 4. 生物

### 魚
- 位置・年齢・繁殖カウンタ

### サメ
- 位置・年齢・繁殖カウンタ・空腹カウンタ

## 5. シミュレーションルール

### 魚
- 毎ステップ、上下左右の空きマスへランダム移動
- 空きマスがなければ移動しない
- 繁殖周期に達すると繁殖（親は消滅しない）

### サメ
- 隣接マスに魚がいれば優先して移動・捕食
- 魚がいなければ空きマスへランダム移動
- 繁殖周期に達すると繁殖
- 空腹カウンタが上限に達すると死亡

## 6. 表示

- Canvas使用
- 海：黒、魚：緑、サメ：赤
- アニメーション（10〜20FPS）

## 7. 操作

- 開始・一時停止・リセット・ステップ実行

## 8. 統計情報

- 現在ステップ数・魚の総数・サメの総数

## 9. パラメータ設定

| パラメータ | 初期値 |
|---|---|
| 盤面サイズ | 50×50 |
| 魚の初期個体数 | 100 |
| 魚の繁殖周期 | 5 |
| サメの初期個体数 | 20 |
| サメの繁殖周期 | 10 |
| 餓死までの時間 | 5 |
| シミュレーション速度 | 10FPS |

## 10. 発展機能

- 個体数の時系列グラフ表示
- シミュレーション条件のJSON保存・読込
