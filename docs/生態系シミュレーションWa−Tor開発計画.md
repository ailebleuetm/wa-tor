# 生態系シミュレーションWa−Tor開発計画

## 基本方針
- 小さなステップ(Phase/Step)で実装する
- 各ステップ終了時に動作確認可能な状態を維持する
- Claude Codeとの対話によるAI駆動開発を実践する
- 初期段階ではフレームワークを導入しない
- 初期段階ではViteを導入しない
- Phase/Stepの設計を進めていきながら、ここのPhase/Stepの設計をブラッシュアップを行い、開発工程を進めていく（仕様の矛盾、設計漏れ/重複、工程の組み直しなど）
